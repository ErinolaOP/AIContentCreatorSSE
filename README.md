# ContentForge AI

ContentForge AI is an AI-powered content creation platform that automatically researches trending topics, writes engaging scripts, generates voiceovers, creates videos, and prepares content for social media scheduling.

## Features

- AI Script Writer
- Trend Research
- AI Voice Generation
- Video Rendering
- Caption Generation
- Thumbnail Generation
- Analytics Dashboard

## Tech Stack

- Python
- FastAPI
- OpenAI API
- FFmpeg
- MoviePy
- SQLite/PostgreSQL
